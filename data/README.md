# Demo data

All files under `data/demo/` are **synthetic demonstration inputs**
(category D), generated by `scripts/generate_demo_data.py` (seed
`20260912`, deterministic `random.Random` — a test-data PRNG, NOT a
cryptographically secure RNG). See `data/manifest.csv` for per-file
SHA-256/MD5, sizes, and coverage notes.

- `DEMO-001` empty byte sequence (edge case).
- `DEMO-002` tiny 37-byte binary payload (nonzero residual).
- `DEMO-003` repeated single byte, 6000 bytes (entropy ≈ 0, zero residual).
- `DEMO-004` repeated structured text ≈ 6 kB (text-like scale class; content
  is original demo text, NOT the manuscript's F8).
- `DEMO-005` deterministic pseudo-random 100 kB (selector branch n=8/12).
- `DEMO-006` mixed header + pseudo-random + trailer 600 kB (n=16/24).
- `DEMO-007` genuine ZIP archive (fixed timestamp) built from demo text —
  a real, openable archive, not random bytes with a `.zip` name.
- `DEMO-008` deterministic pseudo-random 5.2 MB (n=32/48).
- `DEMO-009` repeated structured text 100 kB (n=8).
- `DEMO-010` repeated structured text 600 kB (n=16).
- `DEMO-011` zero bytes 5.2 MB (n=32).

`manuscript_dataset_id` is empty for every row: no demo file reproduces or
stands in for the original F1..F9 manuscript inputs. Repository-owned
synthetic demonstration data are licensed under MIT, confirmed by the
repository maintainer on 2026-10-08 (see `LICENSE` and
`docs/author_questions.md` Q6). This does not license third-party research
inputs or reports under `results/analysis result/`.
